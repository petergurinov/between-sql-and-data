# Between SQL and Data

Репозиторий содержит материалы эксперимента и доклада о том, как результаты запросов передаются из PostgreSQL и ClickHouse в клиентские структуры данных.

## О докладе

**[«Что происходит между SELECT и ДАННЫМИ»](https://smartdataconf.ru/talks/20010937-what-happens-between-select-and-data/)** — доклад Петра Гуринова (Yandex Cloud) на SmartData 2026.

На архитектурных схемах приложение и база данных часто соединены одной стрелкой. Внутри нее работают клиентский API, драйвер, протокол, сетевой транспорт, сериализация, аутентификация, получение метаданных, пакетная передача и сборка результата. В докладе этот слой рассматривается как отдельный архитектурный выбор: сравниваются традиционные интерфейсы, Apache Arrow, ADBC, Flight SQL и протоколы СУБД.

Доклад предназначен для инженеров данных, архитекторов и разработчиков платформ данных, а также специалистов, которые работают с BI, аналитическими инструментами и Python. Репозиторий дополняет доклад воспроизводимым экспериментом: в нем есть измерительный код, результаты замеров и сетевые захваты протоколов.

## Состав репозитория

- [`benchmark/`](benchmark/) — измерительная программа на Python, описание эксперимента, подготовка данных, перечень метрик и итоговые CSV/XLSX для DataLens.
- [`wireshark/`](wireshark/) — сетевые захваты и расшифрованные потоки PostgreSQL, ClickHouse, ADBC, Flight SQL и HTTP-форматов.

Начните с [`benchmark/README.md`](benchmark/README.md): там приведены требования, настройка и команды запуска. Структура итоговой таблицы описана в [`benchmark/results/README.md`](benchmark/results/README.md).

## Сетевые захваты

Все захваты сделаны через loopback-интерфейс `127.0.0.1` в изолированном тестовом окружении. В открытых потоках видны тестовые учетные данные `workshop/workshop` и токены локальных Flight-сессий. Эти значения относятся к опубликованному тестовому окружению.
