# Изменения эксперимента

Изменение способа чтения, SQL, версии зависимости, набора данных, границ измерения времени или правила агрегации создает новую версию эксперимента. Не заменяйте уже опубликованные результаты на месте.

Для новой версии сохраните `manifest.json` с SHA-256 всех входных и выходных файлов. Перед публикацией выполните короткий проверочный запуск и укажите его результат.
