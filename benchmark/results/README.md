# Результаты измерений PostgreSQL и ClickHouse

Основной файл — `measurements.csv`. Это широкая таблица для анализа и загрузки в DataLens. Она содержит 5498 строк: 5475 фактических выполнений и 23 объявленных исхода без строки измерения. В таблице представлены 912 вариантов эксперимента.

- `measurements.csv` — источник данных для DataLens.
- `measurements.xlsx` — те же строки и словарь полей в формате Excel.
- `dictionary.csv` — тип, единица измерения, уровень детализации и рекомендуемая агрегация каждого поля.
- `DATALENS.md` — правила настройки датасета и рекомендуемые страницы дашборда.
- `BUILD.md` — пересборка и проверка файлов.

В таблице есть 893 строки прогрева. Они отмечены как `round=0` и `is_warmup=true` и не входят в основные показатели. Основная статистика рассчитана по 4425 выполнениям.

Поля отдельных выполнений находятся в строках `record_type='execution'`. Принятые показатели варианта имеют префикс `cell_*`. Чтобы на графике оставалась одна строка на вариант, используйте фильтр `is_cell_anchor=true`. Для времени, памяти, CPU и полезной нагрузки отдельных выполнений предусмотрены фильтры `show_time_by_default`, `show_memory_by_default`, `show_cpu_by_default` и `show_payload_by_default`.
