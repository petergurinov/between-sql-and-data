# Методика

Единица эксперимента — отдельный вариант чтения данных, который в файлах называется клеткой (`cell`). Вариант задает СУБД, таблицу, число строк, ширину таблицы, библиотеку, API, транспорт, формат, кодек, конечную структуру и границы измерения времени. Точный план находится в `experiment/cells.json`.

Для каждого варианта выполняется один прогревочный раунд 0 и пять основных раундов 1–5. Порядок вариантов внутри блока перемешивается с фиксированным начальным значением `20260908`. Сравнивать можно только варианты одной группы, у которых совпадают данные, ширина, число строк, конечная структура и границы измерения времени.

Программа записывает строку результата и при успешном выполнении, и при ошибке. Ошибка одного варианта не удаляет результаты остальных вариантов блока. Перед публикацией для каждой попытки блока проверяются число строк, контрольная сумма результата (`digest`), качество сетевых счетчиков и полнота раундов. Итоговый проверенный набор находится в `results/`.

Измерительный код соответствует версии `stand-final-v1.6`, commit `d965b352d3708d6d712b0e4142fc0ea7c2b79552`. Публичный план содержит только варианты, представленные в `results/measurements.csv`.
