# Метрики

Одна строка исходного CSV описывает одно выполнение варианта эксперимента. Программа записывает следующие группы полей:

- время: `wall_s`, `connect_s`, `ttfb_s`, `cleanup_s`, `post_check_s`, `extra_s`;
- память клиентского процесса: `peak_rss_mb`, `rss_settled_mb`, `retained_mb`;
- процессорное время клиента: `cpu_user_s`, `cpu_sys_s`, `cpu_scope`;
- сеть: `bytes_rx_mb`, `bytes_tx_mb`, `packets_rx`, `packets_tx`;
- полнота результата: `rows`, контрольная сумма `digest`, сигнатура схемы `schema_sig`;
- диагностические измерения сервера: `server_time_s`, `serialize_time_s`, `out_kb`;
- происхождение и состояние строки: `status`, `error_class`, `block_attempt_id`, `round`, `ts`, `ts_end`.

`wall_s` измеряет интервал, заданный конкретным способом чтения. Наличие подключения, закрытия соединения и очистки результата внутри этого интервала определяется полями контракта времени в итоговой таблице.

Сетевые поля измеряют изменение счетчиков интерфейса за время выполнения. В них может попасть фоновый трафик хоста, поэтому качество сетевой метрики оценивается отдельно. Расчетную полезную нагрузку нельзя смешивать с байтами интерфейса.

Время, память и CPU следует публиковать только для строк с разрешающим статусом соответствующей метрики. Все 129 полей итоговой таблицы описаны в `results/dictionary.csv`.
