# Измерения передачи данных из PostgreSQL и ClickHouse

Этот каталог позволяет повторить эксперимент по чтению одинаковых результатов из PostgreSQL и ClickHouse разными клиентскими библиотеками Python. Здесь находятся измерительный код, точный план опубликованного эксперимента, правила подготовки данных, тексты запросов, описание метрик и готовый набор результатов для DataLens.

Единица плана — вариант эксперимента, который в файлах и коде называется клеткой (`cell`). Он задает СУБД, таблицу, число строк и столбцов, библиотеку, API, транспорт, формат, кодек, конечную структуру данных и границы измерения времени. В [`experiment/cells.json`](experiment/cells.json) записаны 912 опубликованных вариантов.

Программа подключается к двум заранее подготовленным хостам: `pg` и `ch`. Она не создает виртуальные машины и не устанавливает СУБД.

## Требования

- Python 3.12;
- доступ с клиентской машины к хостам `pg` и `ch`;
- одинаковые тестовые таблицы в обеих СУБД;
- Linux и доступный user cgroup для полного прогона с ограничением памяти.

Для короткой локальной проверки ограничение памяти можно отключить параметром `--no-cgroup`. Такой запуск не заменяет полный прогон.

## Быстрый старт

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp config/benchmark.example.toml config/benchmark.toml
export BENCH_PG_PASSWORD='...'
export BENCH_CH_PASSWORD='...'
.venv/bin/python -m benchmark validate-config --config config/benchmark.toml
.venv/bin/python -m benchmark list-cells --engine pg --max-rows 10000
.venv/bin/python -m benchmark run --config config/benchmark.toml --engine pg --max-rows 10000 --rounds 0,1 --no-cgroup --output artifacts/smoke-pg
```

`validate-config` проверяет обязательные параметры подключения и наличие переменных с паролями. Последняя команда выполняет короткий запуск PostgreSQL на таблицах до 10 000 строк и записывает `raw.csv` и `journal.jsonl` в `artifacts/smoke-pg`.

## Полный прогон

PostgreSQL и ClickHouse запускаются отдельно. Раунд 0 используется для прогрева, а основные показатели рассчитываются по раундам 1–5. Порядок вариантов внутри каждого блока и раунда перемешивается с фиксированным начальным значением генератора.

Не используйте `--no-cgroup` для полного прогона: опубликованный план задает ограничение памяти 120 GiB и отключенную подкачку. Полная последовательность приведена в [`docs/run.md`](docs/run.md).
